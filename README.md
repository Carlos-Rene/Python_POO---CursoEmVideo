# Python_POO---CursoEmVideo

Repositório destinado à realização de atividades e exercícios desenvolvidos em **Python**, com foco em Programação Orientada a Objetos (POO), acompanhando os estudos do curso do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.

## 🛠️ Tecnologias utilizadas

- **Python 3** — Linguagem utilizada no desenvolvimento dos exercícios.
- **Git** — Controle de versão.
- **GitHub** — Hospedagem e gerenciamento do repositório.

## 🎯 Objetivo

Consolidar os conhecimentos em Python por meio da resolução de exercícios práticos, desenvolvendo habilidades de programação, organização de código e aplicação dos conceitos de Programação Orientada a Objetos.

## 📚 Conteúdos

- Classes e objetos;
- Atributos e métodos;
- Construtores;
- Encapsulamento;
- Herança;
- Polimorfismo;
- Relacionamento entre classes.
